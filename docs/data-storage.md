# データ保存仕様

## 基本方針

- 利用者の入力内容は **端末の外へ送信しない**
- 記録の保存は **利用者が「保存する」を選んだときだけ**。初期設定は「保存しない」
- 下書きの自動保存はしない（画面を離れると入力内容は消える）
- 保存データは **暗号化していない**。画面でもそのように説明し、暗号化済みとは表示しない
- 保存したデータは、利用者が一件ずつ、またはまとめて完全に削除できる

## 保存場所と内容

| 保存場所 | キー / 名前 | 内容 | いつ保存するか |
| --- | --- | --- | --- |
| localStorage | `yohaku.settings.v1` | 表示設定（下表） | 利用者が設定を変更したとき（起動しただけでは書き込まない） |
| IndexedDB | DB `yohaku` / ストア `notes` | 置いていったことば | 「この端末に保存する」を押したとき |
| IndexedDB | DB `yohaku` / ストア `feelings` | 気持ちの整理の記録 | 「この端末に保存する」を押したとき |
| Cache Storage | `yohaku-<バージョン>` | アプリ本体のファイル（HTML / JS / CSS / 画像 / manifest） | 初回表示時（Service Worker） |

**保存しないもの**：意思伝達カードの文章、連絡文と入力した名前、少しずつ戻るの進み具合、休憩室の利用時間（計測自体をしない）、閲覧履歴。

### 表示設定（localStorage `yohaku.settings.v1`）

```json
{
  "mode": "standard",          // minimal | standard | full
  "theme": "system",           // system | light | dark
  "fontSize": "m",             // s | m | l | xl
  "volume": 0.4,               // 0〜1
  "reduceMotion": null,        // null（端末に従う）| true | false
  "saveMode": "ask",           // ask（毎回えらぶ）| never（保存機能を使わない）
  "remember": true,            // false のときは {"remember": false} だけを保存
  "restScene": "rain",         // rain | night | sea | forest | stars | dusk | fire
  "restShowText": true
}
```

- 読み込み時に値を検証し、想定外の値は初期値に戻す（`parseSettings`）
- 「表示の設定をこの端末に記憶する」をオフにすると、`{"remember": false}` 以外は保存しない

### 置いていったことば（IndexedDB `notes`）

| 項目 | 型 | 説明 |
| --- | --- | --- |
| `id` | string | `crypto.randomUUID()`（キー） |
| `createdAt` | number | 作成日時（UNIX ミリ秒） |
| `updatedAt` | number | 更新日時 |
| `text` | string | 本文（最大 20,000 文字） |

### 気持ちの記録（IndexedDB `feelings`）

| 項目 | 型 | 説明 |
| --- | --- | --- |
| `id` | string | キー |
| `createdAt` | number | 作成日時 |
| `feelings` | string[] | 気持ちの ID（`anxiety`, `sadness` …。`src/data/feelings.ts`） |
| `note` | string | 任意の文章（最大 4,000 文字） |

点数・評価・病名などの派生データは作らず、保存もしません。記録の画面でも件数の集計やグラフは表示しません。

## 削除

| 操作 | 削除されるもの |
| --- | --- |
| 記録画面の「削除」 | その 1 件 |
| 置いていく場所の「書いた内容を消す」 | 入力欄の文章（保存済みのものは残る） |
| 設定「この端末のデータをすべて削除する」 | IndexedDB のデータベース `yohaku` を削除、localStorage・sessionStorage のうち `yohaku.` で始まるキーを削除、設定を初期化（同じオリジンにある別サイトのデータには触れない） |
| ブラウザの「サイトデータを削除」 | 上記すべて＋オフライン用キャッシュ |

オフライン用のアプリ本体（Cache Storage）は個人の情報を含まないため、「すべて削除」の対象外にしています（削除するとオフラインで開けなくなるため）。

## ローカル保存の限界と注意（画面でも説明）

- 別の端末・別のブラウザには引き継がれない（同期・バックアップ機能はない）
- ブラウザの履歴やサイトデータを消すと、保存した内容も消えることがある
- iOS の Safari では、しばらく使わないサイトのデータが自動で削除される場合がある
- プライベートブラウズでは保存できない、または閉じると消える場合がある（保存できないときはエラーメッセージを表示し、ほかの機能はそのまま使える）
- 共有端末では、ほかの人に見られる可能性がある（暗号化していない）
- 大切な内容は「テキストとして書き出す」で利用者自身が管理できる

## ログ

- アプリはアクセスログ・エラーログを収集・送信しない（ログ送信のコード自体がない）
- ホスティング事業者が通信記録（IP アドレス等）を残す場合がある（docs/deploy.md 参照）。入力内容は通信に含まれない
