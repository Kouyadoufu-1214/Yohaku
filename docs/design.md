# UI デザイン

## コンセプト

静かな空間・自然・温かみ・余白・安心感・シンプルさ。
健康管理アプリのダッシュボードではなく、「紙のような温かい白の上に、少しだけ言葉が置いてある」居場所を目指しています。

- カードを詰め込まず、一覧は罫線で区切った縦のリストを基本にする
- 角は丸く（10〜22px）、影は使わず、細い枠線と面の明るさの差で区切る
- 見出しは丸ゴシック（端末にある場合：ヒラギノ丸ゴ等）、本文は端末標準のゴシック
- 本文 17px 相当・行間 1.85。日本語の文節の途中で改行しにくくする（`word-break: auto-phrase`、対応ブラウザのみ）
- ボタンの高さは 48px 以上（最小表示モードでは 56px 以上）
- 動きはゆっくり（休憩室の背景は 3〜60 秒周期）、点滅なし。OS の「視差効果を減らす」に追従
- 赤や強い原色を使わない。緊急の案内も、落ち着いたベージュの面と文字・アイコンで示す
- 情報を色だけで区別しない（選択状態は ✓ 印・太い枠線、スイッチは「オン／オフ」の文字を併記）

## アクセシビリティ（WCAG 2.2 AA を目標）

| 項目 | 対応 |
| --- | --- |
| コントラスト | 上記。axe-core の自動検査でも違反 0 件 |
| 文字サイズ | 4 段階。ブラウザの拡大にも対応（`user-scalable` を禁止しない） |
| キーボード | すべての操作がキーボードで可能。フォーカスは 3px の枠で表示 |
| スクリーンリーダー | 見出し構造、`aria-current`、`aria-pressed`、`role="switch"`、ライブリージョンでのお知らせ、画面遷移時に見出しへフォーカス |
| ターゲットサイズ | 原則 48px 以上（2.5.8 の 24px を大きく上回る） |
| 動き | 2.3.1（3 回の閃光）に該当する点滅なし。動きを止める設定あり |
| ダイアログ | ネイティブの `<dialog>`（フォーカスの閉じ込め・Esc で閉じる） |

## アイコン・イラスト

- アイコン：24px グリッドの線画を自作（`src/components/Icon.tsx`）
- 休憩室の背景：SVG で自作（`src/components/scenes.tsx`）
- アプリアイコン：余白の中の「。」（`public/icons/icon.svg`）
