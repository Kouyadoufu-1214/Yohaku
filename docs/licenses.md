# 使用素材とライセンスの一覧

## 素材

| 種類 | 内容 | 出典・ライセンス |
| --- | --- | --- |
| フォント | 端末に入っているフォントを使用（ヒラギノ、Noto Sans JP、游ゴシック、メイリオ等。端末により異なる） | 同梱・配布していないため、ライセンス上の手続きは不要。外部フォントの読み込みもなし |
| アイコン | 線画アイコン 36 種（`src/components/Icon.tsx`） | 本プロジェクトで作成 |
| イラスト | 休憩室の背景 7 種（`src/components/scenes.tsx`） | 本プロジェクトで作成（SVG） |
| アプリアイコン | `public/icons/icon.svg` と PNG 4 種 | 本プロジェクトで作成。PNG は `scripts/gen-icons.mjs` で SVG から生成 |
| 環境音 | 雨・夜・波・森・夜風・夕方の風・薪 | 音声ファイルは使用せず、Web Audio API で端末内で合成（`src/lib/audio.ts`） |
| 文章 | 支援コンテンツ、テンプレート、体験談サンプル | 本プロジェクトで作成。体験談はすべて架空のサンプル |
| 引用 | 厚生労働省「ゲートキーパーになろう！」「ゲートキーパーへの支援について」の一部 | 出典を明示して引用。厚生労働省ウェブサイトの利用規約（https://www.mhlw.go.jp/chosakuken/index.html）を公開前に確認すること |
| 相談窓口情報 | 名称・電話番号・受付時間など | 厚生労働省「まもろうよ こころ」、NPO法人あなたのいばしょ、ライフリンクの各公式ページ（2026年11月25日確認）。事実情報として掲載 |
