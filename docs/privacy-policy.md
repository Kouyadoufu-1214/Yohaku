## 1. 基本的な考え方

余白。（以下「本アプリ」）は、利用者の個人情報を集めないことを前提に作られています。会員登録やログインはなく、利用者の入力内容を外部のサーバーへ送ることはありません。

## 2. 集めない情報

- 氏名、メールアドレス、電話番号などの登録情報（登録の仕組み自体がありません）
- 気持ちの記録、書いた文章、作成した連絡文やカードの内容
- アクセス解析・広告・行動追跡のための情報（解析ツール・広告・Cookie を使用していません）
- カメラ、マイク、位置情報、連絡先、通知などの権限（要求しません）

## 3. 端末の中に保存される情報

次の情報は、利用者の端末（ブラウザ）の中にだけ保存されます。運営者が見ることはできません。

- 表示の設定（表示モード、テーマ、文字の大きさ、音量など）：ブラウザの localStorage に保存します。設定で「記憶しない」を選ぶこともできます。
- 気持ちの記録・置いていったことば：利用者が「この端末に保存する」を選んだときだけ、ブラウザの IndexedDB に保存します。初期設定では保存しません。
- オフラインで使うためのアプリ本体のファイル：ブラウザの Cache Storage に保存します。利用者の入力内容は含みません。

保存された内容は暗号化されていません。家族などと共有している端末では、ほかの人に見られる可能性があります。

## 4. 削除のしかた

設定の「この端末のデータをすべて削除する」で、記録と設定を削除できます。記録は一件ずつ削除することもできます。ブラウザの設定からサイトのデータを削除する方法でも、すべて消すことができます。

## 5. 外部のサイトや電話

相談窓口などのリンク先は、それぞれの運営者が管理しています。リンク先での情報の扱いは、各運営者のプライバシーポリシーに従います。本アプリからリンク先へ、参照元の情報（どのページから来たか）は送らない設定にしています。

## 6. 公開しているサーバー（ホスティング）について

本アプリは静的なWebサイトとして公開されます。公開に使うホスティング事業者が、セキュリティなどの目的で、アクセス元のIPアドレスなどの通信記録を保存する場合があります。たとえば GitHub Pages は、サイトの訪問者のIPアドレスをセキュリティ目的で記録・保存すると公式ドキュメントで説明しています（2026年11月25日確認）。

運営者は、これらの通信記録を利用者の分析や追跡のために使いません。利用者の入力内容は、そもそも通信に含まれません。

## 7. 改定

内容を変えるときは、本アプリの中でお知らせします。
