# 今後の改善点

## 公開前に必要なこと（優先度：高）

1. 心理・医療の専門家による全コンテンツの確認（`docs/content-review.md`）
2. 当事者・利用者による操作性の検証、実機・スクリーンリーダーでの確認
3. 相談窓口情報の再確認（特に #いのちSOS・生きづらびっとの休止情報は 12 月に更新）
4. 運営者情報・連絡先の記入、プライバシーポリシー・利用規約の確定
5. ソースコードのライセンス決定

## 機能の改善案

| 案 | 内容・理由 |
| --- | --- |
| 保存データの暗号化（任意） | 共有端末で使う人のために、利用者が決めた合言葉で記録を暗号化する（Web Crypto API の AES-GCM 等）。合言葉を忘れると復元できない点の説明が必要 |
| 記録の書き出し・読み込み | 機種変更に備えて、利用者自身がファイルで持ち運べるようにする |
| 相談窓口の地域別情報 | 都道府県・政令指定都市の「こころの健康電話相談」等を、利用者が選んだ地域だけ表示（位置情報は使わない） |
| 相談窓口の「今つながる可能性がある窓口」表示 | 端末の時刻から受付時間内の窓口を上に表示（祝日・年末年始の扱いに注意） |
| 実在の体験談の掲載 | 同意取得・確認フローを整えたうえで、運営者が確認したものだけを掲載 |
| 多言語対応 | やさしい日本語、英語など |
| 連絡文のテンプレート追加 | 役所・カウンセラー・スクールカウンセラーへの連絡、通院先の変更など |
| 休憩室の音の改善 | 実機での聞こえ方の確認、音の種類の追加（合成音の品質向上） |
| 意思伝達カードの保存 | よく使うカードを端末に保存（保存は任意） |
| 文字の太さ・行間の設定 | 読みやすさの個人差に対応 |

## 技術的な改善案

- 自前のフォントを同梱するかの検討（端末によって見た目が変わるため。ただし日本語フォントは容量が大きい）
- Service Worker の更新を利用者に知らせる控えめな表示（入力中は表示しない）
- e2e テストの CI 化（GitHub Actions で Playwright を実行）
- Safari / Firefox での自動テスト（現在は Chromium のみ）
- コンテンツを Markdown などの外部ファイルに分け、専門家が直接確認・編集しやすくする
